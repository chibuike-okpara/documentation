Each payout has a fee that depends on the network and the amount. The fee is taken from your payout balance **on top of** the amount, so the recipient always gets the full amount you send.

## Check a fee

`POST /v1/transfers/fees` with the `amount`, `currency` and `network` you plan to use.

<CodeGroup>
```typescript nodejs
import ModemPay from "modem-pay";

const modemPay = new ModemPay("sk_test_...");

const feeResponse = await modemPay.transfers.fee({
  amount: 1000,
  currency: "GMD",
  network: "afrimoney"
});

console.log(`Payout fee: ${feeResponse.fee} ${feeResponse.currency}`);
console.log(`Total amount: ${feeResponse.amount} ${feeResponse.currency}`);
```
```python python
from modempay import ModemPay

modem_pay = ModemPay(api_key="sk_test_...")

fee_response = modem_pay.transfers.fee(
    {"amount": 1000, "currency": "GMD", "network": "afrimoney"}
)

print(f"Payout fee: {fee_response['fee']} {fee_response['currency']}")
print(f"Total amount: {fee_response['amount']} {fee_response['currency']}")
```
```php php
use ModemPay\ModemPay;

$modemPay = new ModemPay('sk_test_...');

$fee_response = $modemPay->transfers()->fee([
    'amount' => 1000,
    'currency' => 'GMD',
    'network' => 'afrimoney',
]);

print_r($fee_response);
```
```bash cURL
curl -X POST https://api.modempay.com/v1/transfers/fees \
  -H "Authorization: Bearer sk_test_..." \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 1000,
    "currency": "GMD",
    "network": "afrimoney"
  }'
```
</CodeGroup>

```json
{
  "fee": 5,
  "currency": "GMD",
  "network": "afrimoney",
  "amount": 1000
}
```

Here the recipient gets **1,000 GMD** and your balance goes down by **1,005 GMD**.

<Tip>
  For a [bulk payout](/documentation/payouts/bulk-payout), the response has `total_fees` and `total_chargeable_amount` for the whole batch.
</Tip>
