## What to send

| Field | Required | What it is |
| --- | --- | --- |
| `amount` | Yes | How much to send, in GMD. At least 10. |
| `currency` | Yes | `GMD`. |
| `network` | Yes | `wave` or `afrimoney`. |
| `account_number` | Yes | The wallet's phone number, 7 or 9 digits. |
| `beneficiary_name` | Yes | The wallet holder's name, at least 3 characters. |
| `narration` | No | A note for your records. |
| `metadata` | No | Your own data, like an invoice ID. |
| `callback_url` | No | An HTTPS URL to receive this payout's result. |

You also send an `Idempotency-Key` header: a unique value, like a UUID, for each payout. If you send the same request again with the same key, for example after a timeout, we return the first payout instead of paying twice.

<Tip>
  Not sure what it will cost? [Check the fee](/documentation/payouts/fees) first. The fee is taken from your balance on top of the amount.
</Tip>

## Send a payout

<CodeGroup>
```typescript nodejs
import ModemPay from "modem-pay";

const modemPay = new ModemPay("sk_test_...");

const response = await modemPay.transfers.initiate({
  amount: 100,
  currency: "GMD",
  network: "afrimoney",
  account_number: "7834567",
  beneficiary_name: "John Doe",
  narration: "Vendor payment for April supplies",
  metadata: {
    vendor_id: "vendor_001",
    invoice_id: "inv_204"
  }
}, "Idempotency-Key");
```
```python python
from modempay import ModemPay

modem_pay = ModemPay(api_key="sk_test_...")

response = modem_pay.transfers.initiate(
    params={
        "amount": 100,
        "currency": "GMD",
        "network": "afrimoney",
        "account_number": "7834567",
        "beneficiary_name": "John Doe",
        "narration": "Vendor payment for April supplies",
        "metadata": {"vendor_id": "vendor_001", "invoice_id": "inv_204"},
    },
    idempotency_key="Idempotency-Key"
)
```
```php php
use ModemPay\ModemPay;

$modemPay = new ModemPay('sk_test_...');

$transfer = $modemPay->transfers()->initiate([
    'amount' => 100,
    'currency' => 'GMD',
    'account_number' => '7834567',
    'network' => 'afrimoney',
    'beneficiary_name' => 'John Doe',
    'narration' => 'Vendor payment for April supplies',
    'metadata' => [
      'vendor_id' => 'vendor_001',
      'invoice_id' => 'inv_204',
    ],
], 'Idempotency-Key');
```
```bash cURL
curl -X POST https://api.modempay.com/v1/transfers \
  -H "Authorization: Bearer sk_test_..." \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: Idempotency-Key" \
  -d '{
    "amount": 100,
    "currency": "GMD",
    "network": "afrimoney",
    "account_number": "7834567",
    "beneficiary_name": "John Doe",
    "narration": "Vendor payment for April supplies",
    "metadata": {
      "vendor_id": "vendor_001",
      "invoice_id": "inv_204"
    }
  }'

```
</CodeGroup>

## Look up a payout

<CodeGroup>
```typescript nodejs
const transfer = await modemPay.transfers.retrieve("45eb796c...");
console.log(transfer.status); // e.g., 'completed'
```
```python python
transfer = modem_pay.transfers.retrieve("45eb796c...")
print(transfer["status"]); # e.g., 'completed'
```
```php php
$transfer = $modemPay->transfers()->retrieve("45eb796c...");
echo $transfer->status; # e.g., 'completed'
```
```bash cURL
curl -X GET https://api.modempay.com/v1/transfers/45eb796c... \
  -H "Authorization: Bearer sk_test_..."
```
</CodeGroup>

## Fraud checks

Every payout goes through automatic fraud checks. If one looks unusual:

- its status becomes `pending_review`;
- you get an email and a `transfer.flagged` webhook;
- no more payouts can go to that number until you review it in the dashboard.

Review flagged payouts quickly so your normal payouts aren't held up.

## Common errors

| Message | Fix |
| --- | --- |
| `Invalid transfer amount: … Must be at least 10.` | Send 10 GMD or more. |
| `Invalid account number format. Must be 7 or 9 digits` | Send only digits, no country code or spaces. |
| `Invalid network. Must be one of: afrimoney or wave` | Check the `network` value. |
| `429` with a `code` such as `RATE_LIMIT` | Slow down and retry later. See [Errors](/documentation/errors#error-codes-you-may-see). |
