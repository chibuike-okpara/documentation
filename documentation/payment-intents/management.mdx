## Check a payment

Look a payment intent up by its `intent_secret`, which you got when you created it. Do this on your server before you deliver an order, if you're not using webhooks.

<CodeGroup>
```javascript nodejs
const intent = await modempay.paymentIntents.retrieve("bfa7eb3ea516ee15f80915a922c00242…");

if (intent.status === "successful") {
  // deliver the order
}
```
```python python
intent = modem_pay.payment_intents.retrieve("bfa7eb3ea516ee15f80915a922c00242…")
```
```php php
$intent = $modemPay->paymentIntents()->retrieve("bfa7eb3ea516ee15f80915a922c00242…");
```
```bash cURL
curl "https://api.modempay.com/v1/payments/verify?intent_secret=bfa7eb3ea516ee15f80915a922c00242…" \
  -H "Authorization: Bearer sk_test_..."
```
</CodeGroup>

You get the payment intent back, with its `status`, `amount`, `currency`, `metadata`, `link` and customer.

<Tip>
  Check `amount` as well as `status`. That way you know the customer paid the right amount for the right order.
</Tip>

## List payment intents

<CodeGroup>
```javascript nodejs
const intents = await modempay.paymentIntents.list({ limit: 10 });
```
```python python
intents = modem_pay.payment_intents.list(options={"limit": 10})
```
```php php
$intents = $modemPay->paymentIntents()->list(['limit' => 10]);
```
```bash cURL
curl "https://api.modempay.com/v1/payments?offset=0&limit=10" \
  -H "Authorization: Bearer sk_test_..."
```
</CodeGroup>

```json
{
  "data": [ ... ],
  "meta": { "total": 31 }
}
```

Use `limit` and `offset` to page through. `meta.total` is how many there are in all.

## Cancel a payment intent

Cancel an intent that should no longer be paid, for example when the customer empties their cart or the item sells out. A cancelled intent can't be paid.

<CodeGroup>
```javascript nodejs
await modempay.paymentIntents.cancel("49ac6595-beba-480f-bc3d-33e5d4162c4c");
```
```python python
modem_pay.payment_intents.cancel("49ac6595-beba-480f-bc3d-33e5d4162c4c")
```
```php php
$modemPay->paymentIntents()->cancel("49ac6595-beba-480f-bc3d-33e5d4162c4c");
```
```bash cURL
curl -X PATCH https://api.modempay.com/v1/payments/49ac6595-beba-480f-bc3d-33e5d4162c4c \
  -H "Authorization: Bearer sk_test_..."
```
</CodeGroup>

The intent's status becomes `cancelled` and you get a `payment_intent.cancelled` webhook.
