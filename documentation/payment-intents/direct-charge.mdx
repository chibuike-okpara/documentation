---
title: "Direct charge"
description: "Charge a mobile wallet directly. The customer just confirms on their phone."
---

If you already know the customer's wallet, send the `network` and `account_number` when you create the payment intent. The checkout opens with their wallet already filled in, so they only need to confirm.

This is great for apps where the customer has already given you their number, like a top-up or a delivery app.

| Network | `network` value |
| --- | --- |
| Wave | `wave` |
| Afrimoney | `afrimoney` |
| QMoney | `qmoney` |
| APS | `aps` |

The `account_number` is the 7-digit phone number, **without** the country code.

<CodeGroup>
```javascript nodejs
const intent = await modempay.paymentIntents.create({
  amount: 450,
  network: "wave",
  account_number: "7000001",
});
```

```python python
intent = modem_pay.payment_intents.create(
    params={"amount": 450, "network": "wave", "account_number": "7000001"}
)
```

```php php
$intent = $modemPay->paymentIntents()->create([
    'amount' => 450,
    'network' => 'wave',
    'account_number' => '7000001',
]);
```

```bash cURL
curl -X POST https://api.modempay.com/v1/payments \
  -H "Authorization: Bearer sk_test_..." \
  -H "Content-Type: application/json" \
  -d '{ "data": { "amount": 450, "network": "wave", "account_number": "7000001" } }'
```
</CodeGroup>

Direct charge works with mobile money only. For cards, send the customer to the `payment_link` as usual.

The customer must still approve the payment. Confirm the result with the `charge.succeeded` [webhook](/documentation/core/webhooks), as with any other payment.
