Modem Pay is one API for getting paid and paying people in The Gambia. Your customers pay with **Wave, Afrimoney, QMoney, APS, Yonna or card**. You get one balance, one dashboard and one set of webhooks.

## How it works

<Steps>
  <Step title="Build in test mode">
    Every account starts with test keys (`sk_test_`, `pk_test_`). Nothing you do with them moves real money.
  </Step>
  <Step title="Get verified">
    Submit your business documents (KYC) from the dashboard.
  </Step>
  <Step title="Go live">
    Swap your test keys for live keys (`sk_live_`, `pk_live_`). Your code stays the same.
  </Step>
</Steps>

See [Test mode and going live](/documentation/test-mode) for the full checklist.

## Libraries and tools

| | Install |
| --- | --- |
| Node.js | `npm install modem-pay` |
| Python | `pip install modempay` |
| PHP | `composer require modempay/modempay-php` |
| Laravel | [Laravel package](/laravel/quickstart) |
| WordPress | [WooCommerce plugin](/plugins/woocommerce) and [payment form](/plugins/payment-form) |
| CLI | `npm install -g modem-pay-cli` |

Prefer raw HTTP? Every SDK call is a plain JSON request to `https://api.modempay.com/v1` with your secret key in the `Authorization` header.
