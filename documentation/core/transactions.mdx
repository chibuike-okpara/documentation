title: "Transactions"
description: "Every payment attempt and its result: who paid, how, how much, and when."
---

A transaction is created each time a customer tries to pay. Use transactions to confirm payments, build reports and reconcile with your own records.

## The transaction object

| Field | What it is |
| --- | --- |
| `id` | The transaction's ID. |
| `payment_intent_id` | The payment intent it belongs to. |
| `amount`, `currency` | How much was paid. |
| `status` | `pending`, `completed`, `failed`, `refunded` or `cancelled`. |
| `type` | What it was for, like `payment` or `invoice`. |
| `transaction_reference` | A short reference you can give the customer, like `VOAO1CFEN7`. |
| `payment_method` | How they paid, like `wave` or `qmoney`. |
| `payment_account` | The masked wallet or card, like `.... 9944`. |
| `customer`, `customer_name`, `customer_email`, `customer_phone` | Who paid. |
| `payment_link_id` | The [payment link](/documentation/core/payment-links) used, if any. |
| `custom_fields_values` | Answers to your checkout questions. |
| `metadata` | The data you attached when creating the payment. |
| `test_mode` | `true` for test payments. |
| `createdAt`, `updatedAt` | When it was created and last changed. |

## Get a transaction

<CodeGroup>
```javascript nodejs
const transaction = await modempay.transactions.retrieve("5a24d5d0-1117-4f18-9a44-78112eac8aa1");
```
```python python
transaction = modem_pay.transactions.retrieve("5a24d5d0-1117-4f18-9a44-78112eac8aa1")
```
```bash cURL
curl https://api.modempay.com/v1/transactions/5a24d5d0-1117-4f18-9a44-78112eac8aa1 \
  -H "Authorization: Bearer sk_test_..."
```
</CodeGroup>

<Tip>
  This is how you confirm a payment on your server. Check that `status` is `completed` and that `amount` matches your order before you deliver.
</Tip>

## List transactions

<CodeGroup>
```javascript nodejs
const transactions = await modempay.transactions.list({
  limit: 20,
  search: "wave",
  timeframe: 1440, // last 24 hours
});
```
```python python
transactions = modem_pay.transactions.list(
    options={"limit": 20, "search": "wave", "timeframe": 1440}
)
```
```bash cURL
curl "https://api.modempay.com/v1/transactions?limit=20&search=wave&timeframe=1440" \
  -H "Authorization: Bearer sk_test_..."
```
</CodeGroup>

| Option | What it does |
| --- | --- |
| `limit` | How many to return at once. |
| `search` | Match by currency, reference, payment method or customer. |
| `timeframe` | Only transactions from the last this-many **minutes**. `1440` is one day. |

A restricted key needs the `transactions:read` permission.

To refund a transaction, see [Refunds](/documentation/payment-intents/refund).
